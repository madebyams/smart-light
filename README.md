### Konfiguration der Projekte

Jedes der Projekte hat ein Template für Konfigurationsparameter `config.template.yml`. 
Bei dieser geht man wie folgt vor:

1) Kopiere die Datei "config.template.yml" und benenne sie um zu `config.yml`. Dadurch wird verhindert, dass vertrauliche Daten wie
WLAN Zugangsdaten o.ä. nicht auf diesem Repository öffentlich sind.

2) Starte das Konfigurationsskript mit `python include_config_header.py`, um das Projekt gemäß den angegebenen Parametern zu konfigurieren.

3) Baue das Projekt. :)
